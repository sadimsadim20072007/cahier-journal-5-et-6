# مولّد المذكرة اليومية – المدرسة الرائدة

صفحة ويب ثابتة (ملف واحد `index.html`) تقرأ ملف PowerPoint (`.pptx`) داخل المتصفح وتملأ منه المذكرة اليومية للغة العربية (المستويان الخامس والسادس)، مع إمكانية التعديل ثم الطباعة أو التنزيل بصيغة Word.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `madhakira`).
2. ارفع `index.html` و`README.md` إلى الفرع `main`.
3. من **Settings ← Pages** اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)`.
4. يصبح الموقع متاحًا على: `https://اسم-المستخدم.github.io/madhakira/`

## كيف تُملأ المذكرة؟
- أول سطر في الشريحة الأولى ← **الموضوع**.
- الشرائح التي يبدأ عنوانها بـ «أهداف/كفايات» ← **الأهداف**.
- الشرائح التي يبدأ عنوانها بـ «وسائل/دعامات» ← **الوسائل**.
- باقي الشرائح ← **مراحل الدرس** (عنوان الشريحة اسم المرحلة، ومحتواها أنشطة المدرّس).
- يُستخرج المجال (قراءة، إملاء، تراكيب…) والمستوى تلقائيًا من النص إن وُجدا.
