# المذكرة اليومية – المدرسة الرائدة

صفحة ثابتة (ملف واحد `index.html`) تملأ المذكرة اليومية بشكل الفوجين (الأزرق والبيج) من مصدرين:

1. **JSON** ناتج عن تحليل Claude للملف (PowerPoint أو PDF أو صورة) — هو المسار الموصى به.
2. **ملف `.pptx`** مباشرة (قراءة مبسطة للنصوص داخل المتصفح).

## طريقة العمل الموصى بها
1. في الموقع اضغط **نسخ تعليمة الإخراج (JSON)**.
2. افتح محادثة مع Claude، والصق برومبت التحليل، ثم ألصق في نهايته التعليمة المنسوخة (القسم «ثامنًا»)، وأرفق الملف.
3. انسخ كتلة JSON التي يعطيها Claude.
4. في الموقع اضغط **لصق JSON للفوج الأول** (أو الثاني) والصقها ثم **ملء المذكرة**.
5. راجع المذكرة وعدّل ما تشاء، ثم **طباعة / حفظ PDF** أو **تنزيل Word**.

ملف JSON واحد = فوج واحد. يمكنك تجربة الموقع بزر **إدراج مثال**.

## دلالة العلامات في المذكرة
| العلامة | المعنى |
|---|---|
| (بدون رمز) | معطى صريح وارد في المصدر |
| ◇ | استنتاج ديداكتيكي |
| ✦ | اقتراح ديداكتيكي (غير وارد في المصدر) |
| ⚠ | تعارض داخل المصدر (تُعرض كل الروايات دون حسم) |
| [نمذجة] / [ممارسة موجهة] / [ممارسة مستقلة] | مرحلة التدرج الصريح عند تحديدها |

## بنية JSON (`tarl-journal/1`)
انظر `prompt-json.md` للبنية الكاملة والقواعد، و`example.json` لمثال.
الحقول الإلزامية: `version` و`activities` (كل نشاط له `title`). الباقي اختياري.

## النشر على GitHub Pages
1. ارفع `index.html` و`README.md` و`prompt-json.md` و`example.json` إلى جذر المستودع (Add file ← Upload files).
2. Settings ← Pages ← Deploy from a branch ← `main` و`/ (root)` ← Save.
